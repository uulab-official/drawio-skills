# Round-trip editing

Read this reference when an existing `.drawio` file must become reviewable Diagram IR, or when a generated diagram will be edited in draw.io and returned to source control.

## Extract editable source

```bash
python3 <skill-dir>/scripts/drawio_tool.py extract architecture.drawio \
  -o architecture.diagram.json \
  --report architecture.extraction.json \
  --strict
```

`extract` accepts uncompressed and standard compressed draw.io files. It writes Diagram IR v1 with explicit node positions and sizes, then emits a `drawio-extraction-report/v1` report.

The compiler stores versioned semantic metadata on pages, groups, nodes, and edges. For files generated by v1.1 or later, extraction preserves:

- page IDs, titles, directions, themes, and cross-page links;
- groups and node membership;
- node kinds, descriptions, entity fields, positions, sizes, and supported styles;
- edge IDs, kinds, labels, endpoints, ports, and Crow's Foot cardinalities.

Visible label, page-name, geometry, endpoint, link, and supported style edits override their stored baseline. This lets users move or reconnect elements in draw.io and bring those edits back into the IR.

## Understand the report

- `passed: true` means the recovered IR has no structural errors.
- `lossless: true` means every semantic page and cell used supported compiler metadata.
- `inferred_cells` counts cells whose semantics had to be reconstructed from XML shape, style, label, geometry, or containment.
- `inferred_pages` counts pages whose direction, theme, or identity had to be inferred.
- `--strict` exits `3` when `lossless` is false, while still writing valid best-effort IR.

The report conforms to [extraction-report.schema.json](extraction-report.schema.json).

## Legacy and hand-authored diagrams

For files without compiler metadata, the extractor uses stable deterministic IDs, group containment, shape mappings, connector markers, and page geometry. Review these areas before treating the IR as authoritative:

1. entity fields typed directly into HTML tables;
2. vendor stencil semantics outside the verified shape registry;
3. external hyperlinks, because Diagram IR `link` is reserved for page navigation;
4. free-form edge routing or unsupported visual style tokens.

Run `validate` on the extracted IR and inspect a recompiled preview:

```bash
python3 <skill-dir>/scripts/drawio_tool.py validate architecture.diagram.json --strict
python3 <skill-dir>/scripts/drawio_tool.py compile architecture.diagram.json \
  -o architecture.recompiled.drawio
```

Keep the original `.drawio` until the extraction report and recompiled diagram have been reviewed.

## Security

Round-trip metadata is not a secret store. The `security` command scans visible labels, links, page metadata, semantic cell metadata, and stored visual baselines. Never place credentials, private keys, or confidential payloads in hidden draw.io attributes.
